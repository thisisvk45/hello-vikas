Provenance Guard

A local API that estimates whether writing is human, AI, or unsure, explains why, and lets the writer appeal. Every request gets a receipt in a log, and the receipt never stores the writing itself.

View on GitHub Full RUNNING.md

1Get the code

Needs Python 3.11 or 3.12. No API key.

git clone https://github.com/thisisvk45/ai201-project4-provenance-guard-starter-v2026.git
cd ai201-project4-provenance-guard-starter-v2026

2Install

Takes a few minutes. If python3.11 is missing, use python3.12.

python3.11 -m venv .venv
.venv/bin/python -m pip install -r requirements.lock

3Start the service

Keep this terminal open. It runs on port 5057.

PORT=5057 AI201_DEBUG=0 .venv/bin/python app.py

4Try it

Open a second terminal in the same folder.

curl http://127.0.0.1:5057/health
curl http://127.0.0.1:5057/submit -H 'Content-Type: application/json' --data-binary @fixtures/sample_submit.json
tail -1 logs/requests.jsonl
  • Health returns "ok":true
  • Submit returns "guess":"unsure" with a score of 0.71939
  • The last log line is the receipt: a request_id, duration_ms and model_duration_ms

5Bonus: appeal a decision

Replace the ID with the content_id from your submit.

curl http://127.0.0.1:5057/appeal -H 'Content-Type: application/json' -d '{"content_id":"PASTE_ID_HERE","reasoning":"Please review this estimate."}'

Heads up

The first run downloads GPT-2, about 550 MB. The first request takes around 10 seconds while the model loads. After that, requests take well under a second.

On Windows, activate with .venv\Scripts\Activate.ps1, use curl.exe, and keep each command on one line.
