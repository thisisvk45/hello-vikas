Provenance Guard

Hey! This is my CodePath AI201 final project. You give it some writing, and it guesses if it was written by a human or AI, or says it's not sure. Thanks for trying it out.

Code is on GitHub. You'll need Python 3.11 or 3.12.

1. Download and install

git clone https://github.com/thisisvk45/ai201-project4-provenance-guard-starter-v2026.git
cd ai201-project4-provenance-guard-starter-v2026
python3.11 -m venv .venv
.venv/bin/python -m pip install -r requirements.lock

If python3.11 isn't found, try python3.12.

2. Start it

PORT=5057 .venv/bin/python app.py

Leave this terminal open.

3. Try it

Open a second terminal in the same folder and run:

curl http://127.0.0.1:5057/submit -H 'Content-Type: application/json' --data-binary @fixtures/sample_submit.json

You should get back "guess":"unsure" with a score of 0.71939.

Then check the log, which keeps a record of every request (without saving the writing):

tail -1 logs/requests.jsonl

4. More things to try

Test your own writing (needs at least 40 words and 3 sentences, or it will say "not sure"):

curl http://127.0.0.1:5057/submit -H 'Content-Type: application/json' -d '{"text":"PASTE YOUR TEXT HERE","creator_id":"me"}'

Send something too short. It should say "not sure" and explain why:

curl http://127.0.0.1:5057/submit -H 'Content-Type: application/json' -d '{"text":"Hello there friend.","creator_id":"me"}'

Send bad input. It should be rejected, and still show up in the log:

curl http://127.0.0.1:5057/submit -H 'Content-Type: text/plain' -d 'hello'

Appeal a result (use the content_id you got back):

curl http://127.0.0.1:5057/appeal -H 'Content-Type: application/json' -d '{"content_id":"PASTE_ID","reasoning":"I wrote this myself."}'

See the last few log entries:

tail -3 logs/requests.jsonl

Good to know

The first run downloads a 550 MB model and the first request takes about 10 seconds. After that it's quick. On Windows, use curl.exe and activate with .venv\Scripts\Activate.ps1.
